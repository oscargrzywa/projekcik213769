# 05 - Kompletny system logowania

To samo co przyklad 04, ale pelniejsze:
- `index.php` zamiast `index.html` (sam przekierowuje zalogowanych),
- doszedl `logout.php`,
- panele witaja uzytkownika po nazwie i maja link do wylogowania.

## Pliki
- `baza.sql` - tabela `logowanie` z rola
- `index.php` - formularz logowania
- `login.php` - obsluga logowania
- `logout.php` - wylogowanie
- `admin.php`, `user.php`, `guest.php` - panele

## Dane testowe
- `admin1` / `adminpass`
- `user1` / `userpass`
- `guest1` / `guestpass`
