# Zadania podstawowe (1-5)

Pierwsze cwiczenia z sesji - kazde w osobnym pliku.
Odswiezaj strone w przegladarce, zeby zobaczyc, jak dziala sesja.

| Plik | Zadanie |
|---|---|
| `zadanie1-zapis-imienia.php` | Utworz sesje i zapisz imie uzytkownika |
| `zadanie2-sprawdz-sesje.php` | Sprawdz, czy uzytkownik ma ustawiona sesje |
| `zadanie3-usun-zmienna.php` | Usun zmienna z sesji (`unset`) |
| `zadanie4-zakoncz-sesje.php` | Zakoncz sesje (`session_destroy`) |
| `zadanie5-licznik-odwiedzin.php` | Prosty licznik odwiedzin |

Kolejnosc do przetestowania: 1 -> 2 (widac imie) -> 3 -> 2 (juz nie widac imienia).
